# Capas das coleções do Nuvio

Capas (1280×720, JPG) e logos de título (PNG transparente) das pastas de coleções do Nuvio.

- `capas/<coleção>/<pasta>.jpg` — capa da pasta
- `logos/<coleção>/<pasta>.png` — logo do título

Fontes: Bebas Neue e Montserrat (SIL Open Font License).
Fundos derivados das artes da Kaptain Collection Art, fotos de diretores do Wikimedia Commons e logos de serviços via TMDB.
